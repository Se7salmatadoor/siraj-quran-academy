# سراج لتحفيظ القرآن الكريم أونلاين

صفحة تعريف بأكاديمية سراج ونموذج التحاق. الطالب أو ولي الأمر يملأ الطلب، يراجع الرسالة، ويرسلها بنفسه على واتساب +201062145463.

- الموقع ما بيخزّن أي بيانات ولا بيبعت حاجة تلقائيًا. الرسالة بتتبعت من واتساب عند المستخدم بعد ما يضغط إرسال.
- الاشتراك بأسعار رمزية. السعر وعدد الحصص ومدتها بيتحددوا بالتواصل.
- للأطفال، يملأ ولي الأمر الطلب ويكتب الاسم الأول فقط.

## التشغيل
افتح `index.html` في المتصفح، أو انشر الملفات كموقع ثابت. مفيش تثبيت.

## الملفات
`index.html` الصفحة، `style.css` الشكل، `app.js` بناء رابط واتساب، `mark.png` العلامة.

## English
Landing page and application form for the Siraj online Quran memorization academy (Arabic, right-to-left). The form builds a WhatsApp message to +201062145463; the applicant reviews and sends it from their own WhatsApp. The site stores and sends nothing. Open `index.html` or host as static files.
